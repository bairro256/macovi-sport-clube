# Macovi Sport Clube — Site Oficial\n\nWebsite institucional do Macovi Sport Clube.\n\n## Publicação\n\nO site é publicado automaticamente no GitHub Pages através do workflow **Publicar site Macovi Sport Clube** (`.github/workflows/deploy.yml`) sempre que há alterações na branch `main`.\n\n## Estrutura inicial\n\n- `index.html` — página inicial responsiva, identidade do clube, modalidades, competições e contacto para inscrições.\n- `.github/workflows/deploy.yml` — integração de publicação no GitHub Pages.\n\n## Próximas etapas\n\n- Substituir o emblema provisório pelo símbolo oficial e adicionar fotografias autorizadas.\n- Criar páginas individuais para cada modalidade e escalão (Juvenis/Sub-17 e Juniores/Sub-20).\n- Ligar inscrições, atletas, calendários, resultados e classificações a uma base de dados e área administrativa.\n- Configurar contactos oficiais e redes sociais do clube.\n\nOs calendários e resultados só devem ser publicados após confirmação pelos responsáveis do clube.\n
